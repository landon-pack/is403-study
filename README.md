# IS 403 Study Studio

A static midterm study website with 193 multiple-choice and true/false questions, 215 written prompts, chapter navigation, randomized sessions, hints, and feedback after answering.

Progress and notes are stored in the current browser's localStorage. No API keys, server, or database are required.

## Run locally

Open index.html in a browser, or serve the folder with `python3 -m http.server 8000`.

## Publish on GitHub Pages

In repository Settings → Pages, set the source to **GitHub Actions**. The included workflow deploys the site after pushes to main and can also be run manually.

## Content

Original practice based on topics in chapters 1–22 of the course. Chapter 17 uses lesson topics because its assessment page displayed no questions. This is a study aid, not an official exam or a guarantee of exam coverage.
